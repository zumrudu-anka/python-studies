# 🕊 Get Tweets By SnScrape

## Installing

- run `git clone https://github.com/zumrudu-anka/python-get-tweets-by-snscrape.git` to download repository.
- run `python -m venv venv` to create virtual environment
- run `venv\Scripts\activate` to activate it
- run `pip install -r requirements.txt` to install all dependencies

## Usage

- run `python main.py`
