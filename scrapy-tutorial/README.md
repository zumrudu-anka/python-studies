# 🐍 Scrapy Tutorial

## Requirements

- anaconda

## Additional Informations

- add `FEED_EXPORT_ENCODING = "utf-8"` to `settings.py` to make exports with `utf-8` encoding

## Commands

- `scrapy crawl quotes -o quotes.json` to write output to json file
